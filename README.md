# kareemo.dev

Personal website built with Astro, TypeScript, Tailwind CSS, MDX, and a small React island for the mobile menu.

## Getting started

```bash
npm install
npm run dev
```

## What is implemented

- Shared Astro foundation
- Tailwind 4 design tokens and global styling
- Reusable layout and card components
- Structured placeholder content collections
- Homepage implementation
- Scaffolded placeholder routes for `work`, `projects`, `about`, `now`, and `contact`
